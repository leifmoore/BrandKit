# Decisions

- `_pattern-lib` is a sibling add-on. `_comp-lib` remains frozen at 0.1.0.
- All distributable patterns have React and Blade editions.
- The full EPOS journey is an orchestrated fixture showcase and the reusable
  parts remain separately discoverable.
- Both mobile bottom navigation and contextual action dock are documented; they
  are mutually exclusive in a host layout.
- Reporting ships reusable structures rather than product report pages.
- Charts stay host-supplied; the deferred base Chart component is not promoted.
- Seller PIN and progressive authentication remain reference-only.
- Visual parity is prioritised and unresolved WCAG findings remain visible.
